# Data policy

1. No fabricated values in released observational data.
2. Missing is not zero.
3. Observed, derived and modelled values are explicitly distinguished.
4. Every released field is documented in the variable registry.
5. Every released observation references a source ID wherever applicable.
6. Personally identifying records are excluded from the public core.
7. Administrative boundary changes are versioned rather than silently overwritten.
8. Third-party raw data are redistributed only when source terms permit it.
9. Political parties, candidates and elected representatives are not scored by the core JLA platform.
10. Corrections are versioned and documented.
