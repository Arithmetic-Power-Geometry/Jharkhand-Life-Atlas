# Core Geography & Census Baseline — Module 1

Module 1 is the geographic spine of Jharkhand Life Atlas. Version 1.1.0 bundles a source-backed current administrative hierarchy through block level, Census 2011 district codes, a 24-district official PCA source catalog, a state-level 2011 baseline, and an explicit reconciliation table for conflicting official snapshots.

## Bundled, validated coverage

- 1 state
- 5 divisions
- 24 districts
- 45 subdivisions
- 264 blocks
- 24 Census 2011 district codes
- 24 official district PCA catalog records
- source-reported block-level panchayat/village counts where published
- state-level 2011 population, literacy, social-group and worker facts
- reconciliation records for conflicting official totals

## What this release does **not** claim

The repository does not yet claim a fully ingested entity-level panchayat/village master, full village PCA table, District Census Handbook village amenities, or verified map geometry. Those official source families are registered and discoverable, but raw files must be successfully retrieved and validated before their records are promoted to curated JLA data.

This distinction is intentional: catalog discovery is not raw-data ingestion, and missing data is not zero.
